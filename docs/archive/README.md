# Archive

Frozen on 4 October 2026 by Rob's ruling on #123 ("approve 7"). These documents
described how the project was set up and run in September: the operating model,
the primer on spec-driven delivery, the glossary, the first retrospective, the
repository setup and the issue bootstrap script. The way of working has since
moved into [CLAUDE.md](../../CLAUDE.md), the skills in `.claude/skills/` and the
GitHub issues, and these files stopped being updated.

They are kept for the record and are not maintained. Where one disagrees with
the live docs listed in [docs/README.md](../README.md), the live docs win.

## v1 specs (archived 25 October 2026)

`v1-specs/` holds specs 01–03 (domain model, match engine, fairness ledger) and
the handover prompt, archived by Rob's ruling on #239 (S2) as v1 intent. The
current spec is [feature-specs](../feature-specs.md). Spec 03's outfield-only
fairness rules are superseded by invariant 3 and ADR-015; never build from them.
